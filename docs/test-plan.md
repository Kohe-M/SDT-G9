# テスト計画

## 授業で扱った技術

このプロジェクトでは、授業で扱った「継続的インテグレーション（CI）」と「ソフトウェアテスト技法」を使用します。

GitHub ActionsのCIは、`main` に対するPull Requestおよびpush時に `npm test` と `npm run build` を自動実行します。

## 単体テストの方針

Vitestを使用し、関数内部の実装ではなく入力と出力を確認するブラックボックステストを行います。テストケースは、正常入力、空文字、空白のみ、形式不正、長すぎる入力などの同値分割と、最小有効値、最大有効値、最大有効値 + 1の境界値分析に基づいて設計します。

現時点ではB/C/D担当の完成機能ではなく、今後各担当が利用できる共通バリデーションとFirestore保存前のデータ整形ロジックを単体テストの対象としています。テストではFirebaseやネットワークへ接続しません。

B/C/D担当の機能実装後は、画面の動作やFirebase連携に対する追加テストを行う予定です。

## 実行方法

```bash
npm test
npm run build
```
